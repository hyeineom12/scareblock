# ELAN 설치와 라벨링 준비 (macOS)

라벨링 도구 설정. 한 번만 하면 된다.
라벨 기준은 [`labeling-guide.md`](labeling-guide.md)에 있고, 여기는 도구 얘기만 한다.

## 1. 설치

[ELAN 내려받기](https://archive.mpi.nl/tla/elan/download) — macOS용 `.dmg`를 받는다.
자바가 함께 들어 있어 따로 깔 필요는 없다.

**처음 열 때 막힐 수 있다.** 서명되지 않은 앱이라 Gatekeeper가 잡는다.

- 앱을 **우클릭 → 열기** → 경고창에서 다시 **열기**
- 그래도 막히면 **시스템 설정 → 개인정보 보호 및 보안** 아래쪽에
  *"ELAN을 열 수 없습니다"* 항목이 있다. **그래도 열기** 를 누른다

## 2. 템플릿 불러오기

[`scareblock.etf`](scareblock.etf)에 트랙 5개가 들어 있다. 매번 손으로 만들 필요 없다.

```
File > New...
```

1. 창 왼쪽에서 클립 영상 파일을 골라 오른쪽으로 넘긴다
2. 같은 창의 **Template** 칸에서 `scareblock.etf`를 고른다
3. `OK`

`jumpscare` · `blood` · `syringe` · `spider` · `siren` 트랙이 바로 생긴다.

> 템플릿이 안 먹으면 `Tier > Add New Tier`로 다섯 개를 직접 만들어도 된다.
> 이름만 위와 같으면 변환 스크립트가 읽는다.

**외부 참여자에게도 이 파일을 같이 보낸다.** 트랙 이름을 손으로 치면 `jumpscare`가
`jumpScare`가 되고, 변환 스크립트는 그 트랙을 **조용히 건너뛴다.** 도구를 처음 켜는
사람일수록 템플릿이 필요하다.

## 3. 화면 배치

**파형이 보이는지 확인한다.** 안 보이면 `View > Waveform`.

점프 스케어는 파형에서 **바닥이 수직으로 튀는 지점**이라 눈으로 바로 찾힌다.
영상을 훑어 찾는 것보다 훨씬 빠르고, **어디가 터지는지 미리 알고 보게 되니 덜 놀란다.**

## 4. 구간 찍는 법

1. 파형에서 구간을 **드래그**해 선택
2. 해당 트랙 줄을 더블클릭하거나 `Enter`
3. 라벨 텍스트 입력 — 보통 **비운다.** 애매하면 **`?`** 를 넣는다(`labeling-guide` §5)

**시작점은 정점이 아니라 올라가기 시작하는 지점**이다. 목표 정밀도는 ±0.1초.

찍은 뒤 구간 경계를 드래그해 미세 조정할 수 있다. 파형을 확대(`Ctrl/⌘ +`)하면 맞추기 쉽다.

### 라벨 텍스트가 스키마의 어느 칸으로 가는가

비운 칸과 `?`가 든 칸이 같은 열에 섞이므로, 변환 규약을 여기서 고정한다.

| ELAN 라벨 텍스트 | `ambiguous` | `note` |
|---|---|---|
| (비어 있음) | `false` | (빈 칸) |
| `?` | `true` | (빈 칸) |
| `merged×2` | `false` | `merged×2` |
| `? 케첩인지` | `true` | `케첩인지` |

**`?`는 `ambiguous` 열로 가고, `?`를 뗀 나머지가 `note`로 간다.** `?`는 맨 앞에 쓴다.
`labeling-guide` §1의 두 필드를 한 칸으로 적는 셈이고, §2의 `merged×2`도 같은 칸을 쓴다.

## 5. 내보내기

```
File > Export As > Tab-delimited Text
```

클립마다 하나씩 내보낸다. 변환은 우리가 한다(담당 개발 B).

**대화상자 옵션을 아래대로 고정한다.** 고른 값에 따라 파일 모양이 통째로 달라지고,
각자 다르게 고르면 κ를 재야 할 제3자 파일과 우리 파일이 서로 다른 모양으로 나온다.

- [ ] **시간 형식 — `ss.mmm`(초)**. `labeling-guide` §1 스키마가 초라 변환에서 한 단계가 사라진다
- [ ] **트랙 — 다섯 개 전부** 선택. 사건이 없는 트랙도 포함해서 내보낸다
- [ ] **열 — 트랙 이름 · 시작 · 끝 · 라벨 텍스트**
- [ ] **`duration` 열은 빼둔다.** `offset − onset`으로 계산한다(`labeling-guide` §1)
- [ ] 파일 이름 열은 있어도 되고 없어도 된다 — 변환기가 파일명에서 `clip_id`를 읽는다

> 대화상자 항목 이름은 ELAN 버전에 따라 조금씩 다를 수 있다. **고정해야 하는 것은 항목
> 이름이 아니라 결과 파일의 모양**이다 — 시간이 초이고, 트랙 다섯 개가 모두 있고,
> 열이 위 넷이면 맞다. 처음 내보낸 파일 첫 몇 줄을 팀에 붙여 서로 같은지 한 번 맞춰본다.

## 왜 ELAN인가

오디오 파형 · 구간 라벨 · 다중 트랙을 한 화면에서 다루고, 무료이며 학술에서 인용 가능하다.
한 순간에 여러 카테고리가 겹칠 수 있어 트랙을 나눠야 하는데, 그게 되는 도구가 흔치 않다.
